# Инструкция по настройке гибридного триггера (Cloudflare Worker -> GitHub Actions)

Чтобы бот запускался стабильно каждые 2 минуты, нам нужно связать Cloudflare Worker с вашим репозиторием на GitHub. Выполните следующие шаги:

---

### Шаг 1. Создание токена доступа на GitHub (GITHUB_PAT)
Этот токен нужен Воркеру, чтобы авторизоваться в GitHub и дать команду на запуск экшена.

1. Откройте GitHub и перейдите в настройки вашего аккаунта (не репозитория): 
   Кликните на аватарку в правом верхнем углу -> **Settings**.
2. В левом меню прокрутите в самый низ и нажмите **Developer Settings**.
3. В левом меню выберите **Personal Access Tokens** -> **Fine-grained tokens**.
4. Нажмите кнопку **Generate new token**.
5. Заполните настройки токена:
   * **Token name**: `Cloudflare Trigger`
   * **Expiration**: Выберите максимальный срок (например, 90 дней или Custom -> год).
   * **Repository access**: Выберите **Only select repositories** и выберите ваш репозиторий: `VitaliyNosov/Telegram-Upwork-Bot`.
   * **Permissions**: Раскройте блок **Repository permissions**, найдите строку **Actions** и переключите доступ на **Access: Read and write**.
6. Нажмите кнопку **Generate token** внизу страницы.
7. **Обязательно скопируйте созданный токен** (он начинается с `github_pat_...`). После закрытия страницы увидеть его снова будет нельзя.

---

### Шаг 2. Добавление токена в Cloudflare

1. Перейдите в панель Cloudflare: https://dash.cloudflare.com/
2. В левом меню выберите **Workers & Pages** (или **Compute** -> **Workers & Pages**).
3. Кликните на ваш воркер **`upwork-telegram-bot`**.
4. В верхнем меню выберите вкладку **Settings** (Настройки).
5. В левом меню настроек выберите раздел **Variables** (Переменные).
6. В блоке **Environment Variables** нажмите кнопку **Add variable** (Добавить переменную).
7. Заполните поля:
   * **Name**: `GITHUB_PAT`
   * **Type**: Убедитесь, что выбрано **Secret** (для шифрования).
   * **Value**: Вставьте скопированный на Шаге 1 токен (начинающийся на `github_pat_...`).
8. Нажмите синюю кнопку **Save and deploy** (Сохранить и развернуть).

---

### Шаг 3. Деплой новой версии воркера
После того как вы добавите секрет в Cloudflare, напишите мне в чат, и я выполню финальную команду сборки и деплоя:
```bash
wrangler deploy
```

---

### Шаг 4. Проверка работы
Для теста мы просто перейдем по ссылке вашего воркера в браузере:
`https://upwork-telegram-bot.webdeveloperstudio2017.workers.dev/`

Если всё настроено верно:
1. Браузер выведет: `GitHub Action triggered successfully!`.
2. В репозитории GitHub во вкладке **Actions** мгновенно начнется новый запуск процесса **Poll Upwork Jobs**.

---

### Шаг 5. Отключение старого расписания GitHub
После успешной проверки мы уберем старый таймер из файла `.github/workflows/poll.yml`, чтобы бот не запускался дважды (я сделаю это сам и подготовлю коммит).
